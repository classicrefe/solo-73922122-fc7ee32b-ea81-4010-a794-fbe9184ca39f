# 公交客流月报 · 换基涨跌判定与换基摘要移交

公交客流月报在不同版次间更换过基期（各版基期指数均为 100）。本工具提供两组
功能：

1. **换基涨跌判定**：接收同口径月报 CSV，在勾选版次并选定起止月份后，依据
   **与两月相连的全部换基记录**，严格判定两个月份之间的客流涨跌方向。
2. **换基摘要移交**：把所选月份及其两两之间的**精确比值闭区间**导出为可移交
   的 JSON 摘要；接收方可脱离原始月报，上传一至两份摘要，按**共有月份**拼接后
   查询任意两月的精确比值范围。

## 1. 涨跌判定结果

本工具接收**同口径**月报 CSV，在勾选版次并选定起止月份后，依据**与两月相连的
全部换基记录**，严格判定两个月份之间的客流是：

| 判定 | 含义 |
| --- | --- |
| **必涨** | 所有满足公布数据的指数真值都使止月客流高于起月，并给出源记录证明链 |
| **必跌** | 同理，止月客流必然低于起月，并给出源记录证明链 |
| **无法证实涨跌** | 可行比值区间包含 1，现有记录不足以确定方向（同时给出可行区间） |
| **缺少换算依据** | 两月在勾选版次下不存在相连的换基记录链 |
| **记录存在矛盾** | 相连记录构成负权环（指数区间无法同时成立），暂停判定并列出冲突记录 |

## 1. CSV 格式

UTF-8（或 GBK）编码，首行表头，必需四列（中英文表头均可）：

| 列 | 别名 | 说明 |
| --- | --- | --- |
| 版号 | `version` | 同一版次共享一个基期月 |
| 基期月 | `base_month` | 格式 `YYYY-MM`，该月指数定义为 100 |
| 统计月 | `stat_month` / `月份` | 格式 `YYYY-MM` |
| 公布指数 | `index` | 正整数；真值与公布值之差绝对值 ≤ 0.5 |

示例见 [`samples/demo_monthly_reports.csv`](samples/demo_monthly_reports.csv)。
上传时会逐行校验，所有错误一次性返回（含 CSV 行号）；完全重复的行会被忽略
并给出提示；同一版次出现多个基期月会直接报错。

## 2. 快速开始（Docker Compose）

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

页面操作：

1. 上传 CSV，或直接点击载入内置示例（可涨/矛盾/缺依据三套）；
2. 勾选参与判定的版次，选择起月、止月；
3. 点击「判定涨跌」，查看结论与证明链 / 冲突记录 / 可行区间；
4. 在「导出换基摘要」中勾选要移交的月份，点击「导出摘要」，可下载 JSON 或直接
   登记到下方拼接查询；
5. 在「接收方」区域上传一至两份摘要（或载入内置摘要示例），选择一至两份、
   设定起止月，点击「拼接查询」。

停止：`docker compose down`。

## 3. 换基摘要（导出 / 拼接）

### 3.1 摘要内容

摘要只含**所选月份**与它们两两之间的**精确比值闭区间**：

```json
{
  "format": "bus-transfer-summary",
  "format_version": 1,
  "tolerance": "1/2",
  "months": ["2020-07", "2022-07"],
  "pairs": [
    {"from": "2020-07", "to": "2022-07", "low": "46361/44600", "high": "47241/44200"}
  ]
}
```

- 端点一律是**分数**（`分子/分母` 或整数），不含小数，避免移交过程中的精度损失；
- 区间计算**可以经过未移交的月份**（上例经过 2021 年的中间版次）；
- 对差分约束系统，消去中间月份后剩余的投影约束恰是所选月份上的两两最紧
  区间，所以**导出前后所选月份可同时成立的客流比例组合完全一致**。测试
  `test_single_summary_preserves_feasible_ratio_combinations` 逐对校验了这一点，
  另有 1000 组随机采样的数值校验；
- 若与任一所选月相连的源记录存在矛盾（负权环），**拒绝导出**并返回冲突 CSV
  行号与受影响月份；
- 所选月份若两两不连通，摘要不记录该月对；接收方查询时会得到“缺少换算依据”。

### 3.2 拼接查询

接收方上传一至两份摘要，系统把它们按**共有月份**并入同一张精确约束图：

| 结果 | 含义 |
| --- | --- |
| `ok` | 两月连通且所在分量无矛盾，给出合并约束下 `F(止月)/F(起月)` 的精确闭区间，并附单份摘要原先可查询的范围（已按合并约束重算） |
| `no_basis` | 两月不连通（含两份摘要无共有月份），提示缺少依据 |
| `conflict` | 两月连通但所在分量存在矛盾，停止换算，列出冲突涉及的摘要名称/ID 与月对 |

两份摘要共有月份的重叠区间会同时生效，因此合并结果可能比任何单份摘要更紧；
页面会标注 `tightening` 并保留每份摘要原先能给出的范围用于对照。

## 6. 判定原理（差分约束 + 最短路径）

设月 `m` 真实客流为 `F(m)`。一条记录（版 `v`，基期 `b`，统计月 `m`，公布
指数 `I`）给出：

```
(I - 0.5)/100 ≤ F(m)/F(b) ≤ (I + 0.5)/100
```

令 `x_m = ln F(m)`，取对数后成为差分约束，转为两条有向边：

- `b → m`，权 `ln((I+0.5)/100)`（比值上界）
- `m → b`，权 `-ln((I-0.5)/100)`（比值下界的反向约束）

对起月 `s`、止月 `e`，令 `d = x_e - x_s = ln(F(e)/F(s))`：

- Bellman-Ford 求 `s → e` 最短路，得 `d` 的上界 `U`；
- 求 `e → s` 最短路，得 `d` 的下界 `L`；
- `U < 0` ⇒ 必跌；`L > 0` ⇒ 必涨；否则区间含 1，无法证实；
- 图中存在负权环 ⇒ 约束无解 ⇒ 记录互相矛盾，回溯前驱边列出环上记录；
- `s`、`e` 不在同一无向连通分量 ⇒ 缺少换算依据。

判定只使用与起、止两月同属一个连通分量且来自勾选版次的记录（即“与两月相连
的全部换基记录”）。证明链由最短路径的前驱边重建，每一步都标注其 CSV 源行号、
所用上/下界及比值区间，各步区间连乘即总体可行区间。

摘要功能使用同一模型，但把权重换成**精确有理数**做乘法版 Bellman-Ford
（`app/exact.py`）：`x_v - x_u ≤ ln(w)` 中最短乘积即最小比值，比较用
`fractions.Fraction` 严格进行，因此区间端点是精确的。负环判据为环上权重乘积
`< 1`（恰为 1 视为相容）。

## 7. 目录结构

```
app/
  logic.py          # 解析、建图、浮点 Bellman-Ford、判定与证明链
  exact.py          # 精确有理数差分约束引擎（导出/拼接使用）
  summary.py        # 摘要导出、JSON 校验、按共有月份拼接查询
  main.py           # FastAPI 路由（上传/示例/判定/摘要导出/拼接）
  static/index.html # 单页前端（判定 + 导出 + 拼接查询）
samples/            # 三套月报示例 CSV + 四份摘要示例 JSON
tests/              # pytest 用例（逻辑 + 摘要 + API）
Dockerfile, docker-compose.yml, requirements.txt
```

## 8. 说明与限制

- 数据集与已上传摘要保存在进程内存中（演示用途），重启服务后需重新上传；
- 已上传摘要最多保留 100 份，拼接查询一次最多选择 2 份；
- 月份按 `YYYY-MM` 字符串处理，字典序即时间序；
- 基期月等于统计月的自指记录（基期本身，指数恒为 100）不含比较信息，建图时
  自动跳过。
